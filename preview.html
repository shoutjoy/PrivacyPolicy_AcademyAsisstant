학술도구 어시스턴트

연구 · 논문 · 강의자료 · 발표자료 · 영상제작 통합 플랫폼

1. 학술도구 어시스턴트란?

학술도구 어시스턴트는 연구자, 교수, 대학원생, 강사 및 전문직 종사자를 위한 AI 연구 지원 플랫폼입니다.

논문 작성, 통계 분석, 문헌 검토, 발표자료 제작, 강의 콘텐츠 제작을 하나의 환경에서 수행할 수 있습니다.

2. 주요 기능

Assistant

AI와 직접 대화하며 연구, 논문, 분석, 보고서 작성 지원

Prompt Library

전문 프롬프트 저장 및 재사용

View Editor

AI 결과를 문서 형태로 정리 및 편집

Scholar NotebookLM

PDF 논문 분석 및 문헌고찰 지원

Gemini Notebook

대용량 문서 분석 및 요약

MD Editor

Markdown 문서 편집기

rHWP

한글(HWP) 수식 및 논문 작성 지원

PDF2PPT Make

PDF → 발표자료(PPT) 자동 생성

VIDEO ENGINE JENA PRO

이미지 + 오디오 기반 영상 제작

3. Prompt Library 사용법

Prompt는 AI에게 지시하는 명령어입니다.

예시

"구조방정식 결과를 APA 형식으로 작성해줘"
"이 논문의 연구문제를 생성해줘"
"중학생 대상 수학 강의안을 만들어줘"

4. View Editor 사용법

AI가 생성한 결과를 편집하고 저장하는 공간입니다.

  • 논문 초안 작성
  • 연구노트 정리
  • 보고서 작성
  • 강의자료 제작
  • Markdown 편집
